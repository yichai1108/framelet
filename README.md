# 片言菲林 Framelet

一个为文学随笔设计的中英双语静态网站，可直接托管在 GitHub Pages。

## 网站内容

- 首页序言、Logo 与按年份浏览的文章档案
- 每篇文章显示标题、日期及可用配图
- 阅读页左侧为英文文学翻译，右侧为中文原文
- 手机端可在英文与中文之间切换
- 返回主页时恢复进入文章前的滚动位置
- 不依赖框架、数据库或外部字体

## 本地预览

在本文件夹中启动任意静态文件服务器，然后打开首页即可。不要直接双击文件预览，因为浏览器对本地文件的历史记录行为可能不同。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库。
2. 将此文件夹内的全部文件上传到仓库根目录。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. 选择 main 分支和根目录并保存。

GitHub 完成部署后会显示网站地址。

## 修改文章

文章、日期、配图和翻译都集中在 content.js。新增文章时复制一组文章对象并修改内容即可。
